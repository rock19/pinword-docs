常见问题

  • 如何更换教材？打开"我的"页面 → 教材维护 → 选择年级、学期和教材版本即可。
  • 如何恢复购买？订阅页面底部点击"恢复购买"，使用购买时相同的 Apple ID 登录即可。
  • 如何取消订阅？iPhone/iPad 设置 → Apple ID → 订阅 → 选择 PinWord → 取消订阅。
  • 数据会丢失吗？学习数据通过 iCloud 自动同步。请确保设备已登录 iCloud 且 iCloud 云备份已开启。
  • 如何添加背单词搭子？打开"搭子"页面，将你的邀请码分享给同学，对方输入后互相确认即可。
  • iPad 和 iPhone 数据不同步？请在两台设备上使用同一个 Apple ID 登录，并开启 iCloud 同步。
